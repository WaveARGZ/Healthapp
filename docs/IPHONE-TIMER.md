# iPhoneの休憩タイマー

BodyMakeの休憩タイマーを開き、「iPhoneの時計へ切り替える」を押すと、残り時間（秒）を専用のショートカットへ渡します。ロック画面と終了音はiPhoneの標準「時計」が担当します。追加のAPI・サーバー・課金サービスは使いません。

## 初回設定

1. iPhoneの「ショートカット」で新規作成し、名前を **BodyMake休憩タイマー** にします。
2. 「時計」の **タイマーを開始** アクションを追加します。
3. 時間の数字を長押しして **ショートカットの入力** を選択し、単位を **秒** にします。保存します。
4. BodyMakeで10秒に設定して「iPhoneの時計へ切り替える」を押します。「時計」で10秒のタイマーが実際に開始したことを確認します。
5. iPhoneをロックし、残り時間の表示と終了音を確認します。「時計」の「タイマー終了時」は音を選択してください。「再生停止」では鳴りません。Dynamic Islandは対応機種でのみ利用できます。

ショートカットは利用するiPhoneで初回設定が必要です。BodyMakeのWebページから自動インストールはしません。アクション名・変数の選択表示はiOSのバージョンで異なる場合があります。

## 動作と制限

- Appleの公開URLスキームで専用ショートカット名と1〜86,399秒の整数だけを渡します。アカウント・食事・運動の記録、クリップボードは渡しません。
- 起動時点で残り時間を再計算します。バックグラウンドで最後の描画が古い場合も、その数字を流用しません。端数は1秒単位で切り上げます。
- 切り替え時はWeb側の計測と音を止めます。URLを開いたことを「時計」の開始成功とは扱いません。戻った画面で開始確認を案内し、二重起動の連打を防ぎます。
- 「時計」の実際の開始・一時停止・延長・終了はWeb側から読み取れません。「時計」で操作してください。「開始されなかった／時計を停止済み」でWeb画面を戻しても、ネイティブ側のタイマーは停止しません。
- ページを再読み込み・移動すると確認表示は消えますが、「時計」のタイマーは残り得ます。再起動前に「時計」を確認してください。既存のタイマーを自動で変更・削除しません。
- ショートカット未設定・起動拒否・アプリ内ブラウザの制限時は、初回設定または標準「時計」での手動開始を案内します。
- 通常の「開始」は従来のWebタイマーです。iOSがWebページを停止するため、ロック中や画面を閉じた状態での終了音は保証できません。

## 検証

`npm run test:workout-timer` でURLの入力制限、停止中・一時停止中・バックグラウンド後の時間受け渡し、期限切れ、連打、Webとの二重発音防止、起動拒否後の復帰、既存音声セッションの解放をRAMのモックで確認します。

実機では上記の10秒テストに加えて、Safariとホーム画面からの起動、別アプリ使用中、音楽再生中、ショートカット未設定、開始確認画面からの復帰を確認してください。モック検証を実機でのロック表示・終了音の成功とは扱いません。
